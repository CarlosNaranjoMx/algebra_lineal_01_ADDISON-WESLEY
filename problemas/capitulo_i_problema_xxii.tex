\section*{Problema 3}

Demuestra que las rectas

\[
3x - 5y = 1, \quad 2x + 3y = 5
\]

no son perpendiculares.

\textbf{Solución:}

Para determinar si dos rectas son perpendiculares, verificamos si el producto de sus pendientes es igual a $-1$.

La pendiente de una recta en la forma $ax + by = c$ está dada por $m = -\frac{a}{b}$.

Para la primera recta $3x - 5y = 1$:

\[
m_1 = -\frac{3}{-5} = \frac{3}{5}
\]

Para la segunda recta $2x + 3y = 5$:

\[
m_2 = -\frac{2}{3}
\]

El producto de las pendientes es:

\[
m_1 \cdot m_2 = \frac{3}{5} \cdot \left(-\frac{2}{3}\right) = -\frac{6}{15} = -\frac{2}{5}
\]

Dado que $m_1 \cdot m_2 \neq -1$, las rectas no son perpendiculares.
